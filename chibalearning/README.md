# AI Career Path

ต้องการทำWebApp สำหรับการเรียนรู้กำหนดว่าถ้าเราอยากเป็นอาชีพแบบนี้ๆต้องเรียนอะไรบ้าง
เพื่อให้เราสามารถเรียนรู้ได้โดยไม่เกินหลงทางหรือ รู้อะไรเกินไป
โดยใช้AI เป็นตัวช่วยในการกำหนดเส้นทาง Career path 
ขอบเขตวิชาที่คิดไว้จะมีพวก Coding, Science, 
คุมธีมเป็นแบบ High-Quality Pixel 16bit 
1.กำหนดให้หน้าแรกเป็นหน้าตาแบบ แชทกับAI
2.พอสรุปได้แล้วว่าอาชีพแบบนี้ต้องเรียนอะไรบ้างมีหน้าต่าง
Node learning เหมือน App duolingo ให้เราเรียนรู้ไปที่ละระดับ
3.ถ้าเป็นหน้าสำหรับเรียนรู้ การCoding ก็จะมีเนื้อหาให้เรียนคำอธิบายด้านซ้าย ขวาบนเป็น Editor 
และมีTerminal อยู่ขวาล่างเหมือนเป็น Codedex หรือที่ไว้สำหรับเรียนไปลองไป

4.จะมีการให้ Quiz หรือ บททดสอบว่าเราเข้าใจได้มากแค่ไหนด้วย
5.Feature ที่จะทำให้ตัวเว็บเราไม่เหมือนใครคือ จะมีตัวละครPixel ไว้สำหรับเป็น Character ของเราไว้สำหรับเล่นเกมได้ด้วย 
6.ในทุกหน้าการเรียนรู้อยากให้จะมีไอคอนที่เราสามารถถามAI ในเรื่องที่สงสัยในแต่ละบทเรียนได้
7.สามารถ Login ได้
8.เมื่อเราเรียนครบทุกNode แล้วสามารถขอCertificate ตอนสุดท้ายได้ด้วย
